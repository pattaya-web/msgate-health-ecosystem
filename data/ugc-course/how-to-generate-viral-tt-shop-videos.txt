Generating The Character


The way we will generate the consistent character is really simple.


First, pick an image you want to clone (your competitors podcast video, dr barbara, etc…) you know what i mean. (copying is better than creating from scratch for ai)


Now we will use this prompt:
NANO BANANA PRO PROMPT


Here's the step-by-step workflow:


* 1. Open Gemini
* 2. Upload image you want to clone
* 3. Use the nano banana pro prompt for cloning
* 4. Use that prompt to generate an image with nano banana pro 


In the sections below, I'll walk you through the complete workflow for using this character across multiple ai tools and how to lipsync it.


Cloning a Voice with Elevenlabs


VERY IMPORTANT
It's always better to copy a voice than to use a default one.


ElevenLabs has two different options that I like:
1. Instant voice clone
2. Voice Design


INSANT VOICE CLONE


I like to use instant voice clone. When I copy voices, they sound better than the ones i generate.
Here’s how it works:
* Download a video from yt/tt/reels
* Make it an mp3
* Upload it to 11labs instant voice clone feature
* That’s it


  



You can even use professional voice clone if you want to go deeper but not that necessary.


VOICE DESIGN


This one is good also, you can design a voice and change the accent etc.

Use this prompt to design a voice:
ELEVENLABS VOICE DESIGN




Here’s how it works:
* Upload image/video to gemini
* Use the prompt on the docs above
* Upload it to 11labs instant voice clone feature
* That’s it


  



#1 Heygen Avatar IV
Heygen Avatar IV is pretty good at lipsyncing image to video, the 1080p results are pretty good.


This is the video i generated


heygen-1080p.mp4




Here’s the workflow:
- Generate the voice with elevenlabs
- Go to heygen > create image to video
- upload the image you generated with nano banana pro
- upload the voice
- choose faster generation mode
- i left custom motion prompts empty   


This is it, it’s really simple but effective.
