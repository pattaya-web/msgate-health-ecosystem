# Affiches des styles intégrés

Dépose ici les captures des créas de référence, nommées par identifiant de
style. Dès qu'un fichier est présent, la Bibliothèque affiche la vraie image
à la place de l'aperçu dessiné. Formats acceptés : `.jpg`, `.jpeg`, `.png`, `.webp`.

| Fichier à déposer                  | Style                                        |
| ---------------------------------- | -------------------------------------------- |
| `builtin-claim-callouts.jpg`       | Promesse + 4 bénéfices fléchés (fond bleu)   |
| `builtin-struggling-list.jpg`      | « Struggling with ? » + liste NO MORE        |
| `builtin-bold-statement.jpg`       | Déclaration choc + 4 mini-claims (fond noir) |
| `builtin-sale-tape.jpg`            | Bannière promo + ruban « Buy 1 Get 1 »       |
| `builtin-announcement-letter.jpg`  | Lettre d'annonce sur fond rouge              |
| `builtin-cartoon-reaction.jpg`     | Réaction cartoon + claim souligné (violet)   |
| `builtin-bed-scene.jpg`            | Scène intime + emoji (lit)                   |
| `builtin-serif-two-columns.jpg`    | Titre serif + deux colonnes d'icônes (bleu)  |
| `builtin-wall-reveal.jpg`          | Mur cassé + checklist de bénéfices           |
| `builtin-body-overlay.jpg`         | Photo corps + titre script + flèches         |

Ce dossier n'est pas versionné : ce sont des créas d'autrui, elles restent
sur ta machine.
