# Vidéos de référence

Dépose ici les créas que tu veux reproduire (mp4, mov). Puis :

    npx tsx scripts/analyze-references.ts

Chaque vidéo obtient un dossier avec une image par plan et un `report.md`
(plans, cadrages, transcription). C'est ce que Claude lit pour comprendre
ce qu'il faut reproduire et construire l'outil autour.

Ce dossier n'est pas versionné.
